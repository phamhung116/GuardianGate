## Approved stack and constraints

- Runtime/framework: Next.js App Router + TypeScript, with protected route handlers in the same codebase.
- Database engine: PostgreSQL 16 with Prisma ORM and local migration/seed path.
- Identity and policy: TideCloak Dev OIDC, QEA for governed admin writes, Forseti C# contract for policy authority.
- Deployment target: Local-only demonstration; Docker Compose for PostgreSQL and TideCloak Dev.
- Existing conventions to preserve: Greenfield workspace; product and architecture documents are canonical.
